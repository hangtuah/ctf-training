# Bahagian 2 - Linux command basic (essential untuk CTF)

Objektif:
- Peserta boleh navigate file dan guna command untuk analisis.
- Asas untuk semua challenge selepas ini.

Command diperkenalkan:
- ls, cd, cat, file, strings, grep, head, tail, pwd

Mini latihan:
1. Tunjuk isi folder: `ls -l`
2. Baca file: `cat filename.txt`
3. Guna grep: `cat filename.txt | grep keyword`
